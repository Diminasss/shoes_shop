git init - создать репозиторий

git branch -m main - переименовать текущую ветку master в main

git remote add origin *ссылка на репозиторий на github* - подключение репозитория к пустому удалённому на GitHub

git add . - добавить в индекс все файлы для первого (или последующих коммитов)

git status - узнать файлы из индекса

git commit -m "Комментарий к комиту" - создать коммит с файлами из индекса

git push origin main - отправить коммит в ветку main  в удалённом репозитории github

git branch develop - создание ветки develop для разработки

git checkout develop - переключение на ветку develop
